1. 프로젝트 개요 및 현재 상태

국민연금공단(NPS)의 공개 국내주식 보유내역을 일별 종가로 재평가해 NAV 추이를 KOSPI와 비교하고, 기금 전체 자산군 비중 추이까지 보여주는 정적 대시보드다. GitHub Actions가 평일 1회(16:20 KST) 데이터를 갱신·커밋하고 GitHub Pages로 배포한다. 서버·DB·프레임워크가 전혀 없는 极단적으로 단순한 스택이며, 이 단순함 자체가 이 프로젝트의 가장 큰 자산이다.

#심각도이슈근거 위치
I-1높음 발행 전 데이터 검증 부재. 일간 NAV ±8% 같은 극단값, 가격 결측률, 0원 가격 등을 점검하지 않고 그대로 발행. 잘못된 데이터가 "공식처럼" 노출될 수 있음. write_outputs() 직전 검증 단계 없음 (fetch_data.py:1043)
I-2높음 기업행위(액면분할·병합·감자) 미처리. 수량 고정 + 무수정 원주가 모델이라 분할 1건이 해당 종목 평가액을 1/n로 왜곡. 시총 상위 종목이면 NAV 전체가 틀어짐. NAV 모델 전제 (fetch_data.py:781–814)
I-3높음 무제한 forward-fill. 거래정지·상폐 종목이 마지막 가격으로 영구 평가에 잔류. 한도(예: 10거래일) 초과 시 제외/경고 필요. df.sort_index().ffill() (fetch_data.py:798)
I-4높음 구성 기준일·폴백 상태가 UI에 미노출. 현재 18개월 전 구성(seed 2024-12-31)으로 운영 중인데 화면은 "기준일=오늘"만 표시. DATA.source는 만들어 놓고 렌더하지 않음. index.html:201–216 (renderSummary), 정적 source-note(91행)
I-5중간 테스트 전무 + 조용한 폴백. 소스 HTML/CSV 포맷이 바뀌면 예외 → 경고 로그 → seed 폴백으로 "성공처럼" 종료. 회귀를 알아챌 방법이 스케줄 로그 열람뿐. 저장소 전체 (tests/ 부재), except Exception: pass (fetch_data.py:717, 745)

6. 리팩토링 권고안

전면 재작성은 권하지 않는다. 현재 코드는 도메인 지식의 결정체이고, 동작도 한다. 대신 "안전망 먼저, 구조는 그 다음" 원칙으로 3단계를 제안한다. 각 Phase는 독립적으로 배포 가능하며, 이전 Phase 없이 다음을 진행하면 리스크가 커진다.

Phase 0 — 안전망과 정직성 (1–2일, 최우선)

구조를 건드리기 전에 "틀린 데이터가 조용히 나가는" 경로부터 막는다. I-1, 3, 4, 7, 9, 10 해소.

  • 발행 전 검증 게이트 추가 — 실패 시 발행 중단(기존 데이터 유지)하고 Actions를 실패시켜 알림: 
    # validate.py (신규) — write_outputs() 직전 호출
MAX_DAILY_NAV_MOVE_PCT = 7.0      # KOSPI 서킷브레이커 1단계(8%) 미만으로 보수 설정
MAX_STALE_TRADING_DAYS = 10       # ffill 허용 한도
MIN_PRICED_RATIO = 0.95           # 가격 수신 종목 비율 하한

def validate(nav_hist, holdings, prices) -> list[str]:
    errors = []
    for prev, cur in zip(nav_hist, nav_hist[1:]):
        move = (cur["nav"] / prev["nav"] - 1) * 100
        if abs(move) > MAX_DAILY_NAV_MOVE_PCT:
            errors.append(f"{cur['date']} 일간 NAV {move:+.1f}% — 이상치/기업행위 의심")
    priced = sum(1 for h in holdings if prices.get(h["stock_code"]))
    if priced / max(len(holdings), 1) < MIN_PRICED_RATIO:
        errors.append(f"가격 수신율 {priced}/{len(holdings)} — 소스 장애 의심")
    return errors
    의심 종목(전일 대비 ±30% 등)은 발행물 warnings 필드에 동봉해 화면에 표시할 수 있게 한다.
  • ffill 한도: ffill(limit=10) + 한도 초과 종목은 당일 평가 제외·로그. (I-3)
  • UI에 출처 배지: 요약 카드 옆에 구성 기준 2024-12-31 (연말 공시) · 가격 기준 {asOf}를 항상 노출. DATA.source가 seed면 "공시 기준 구성" 안내 문구. (I-4)
  • 의존성 고정: pykrx==1.0.51처럼 검증된 버전으로 핀 + 미사용 requests 제거. 업그레이드는 의도적 PR로만. (I-7)
  • 실패 알림: 워크플로 마지막에 if: failure() step으로 이슈 자동 생성(또는 Telegram webhook). 연속 seed 폴백 N일째도 경고 대상. (I-9)
  • 청소: seed_nav_history.json 삭제(또는 docs/archive로 이동), README의 "누적" 서술을 "매회 재계산"으로 정정. (I-10)
